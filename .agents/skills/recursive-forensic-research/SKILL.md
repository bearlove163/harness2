# Recursive Forensic Research Skill (基于 Harness² 的多维递归深度调研与溯源)

本技能指导智能体在面对复杂重大工程、科技设施、大跨空间结构、超高层摩天大楼、综合交通枢纽或高规格政体场馆等课题时，运用双层递归、对抗探针、多领域力学/物理基准核验以及多模态工程视觉图谱生成，交付具备工程级信度、**全流程章节级图文互证（Chapter-by-Chapter Visual Anchoring）**与反思深度的专业研究简报与学术专著。

```

         │
         ▼
[阶段 2: 任务级三阶段探针生成]
  ├─ Probe-Alpha (考古探针) ──> 【图版响应 2~4】真实历史档案照片/图纸 (总师蓝图/原点建设/历史演变)
  ├─ Probe-Beta  (本构探针) ──> 【图版响应 5~7】深层力学剖切/FEA应力云图/特色水工机电全流程图
  └─ Probe-Gamma (对抗探针) ──> 【图版响应 8~9】隐患动力学图解(逆重力防排烟/疏散)/高负荷实景
```

## 阶段 1：时空锚点前置锁定（Temporal Guardrail）

1. **提取系统当前时间**：在执行任何检索之前，读取环境元数据或提示词中的当前物理时间（年、月、日）；
2. **构建时效硬约束关键词**：
   * 严禁无时间限制地搜索宽泛历史词条；
   * 搜索词必须显式绑定目标时间窗口（如查询近期1个月，若系统当前时间为 2026-10，则检索式必须强制锁定 `"September 2026"`、`"October 2026"` 或 `"2026"`）；
3. **前置跨年校验**：若抓取到的公开页面为往届信息（如 2024 年旧闻），必须明确标识为“历史对比样本”，不得当做当前现状汇报；
4. **【视觉响应 1】**：完成本阶段后，必须就地生成或配置 **项目全景概览、关键运营指标与核心参建联合体网络图板（Project Profile & Consortium Dashboard）**，紧随正文呈现。

## 阶段 2：任务级递归探针生成（Propose–Probe–Compose）

面对调研目标，智能体不可直接单兵搜索，应在任务级递归中自发构建 3 组对抗探针，并为每组探针完成**“事实推演 + 视觉互证”**闭环：

* **Probe-Alpha（源流与演变考古探针）**：
  * **事实挖掘**：追溯项目原点（何时由谁构想？最初的结构/规划范式是什么？）、关键突变节点（灾变事故、赛事升级改建、产权易手）、主导大师与设计流派（主持建筑师与核心结构顾问的设计哲学与技术渊源）；
  * **【视觉响应 2~4】**：检索并嵌入真实历史档案照片（总师蓝图手稿、母体初建工地实况、不同改建历史时期的旧照对比，优先 Wikimedia Commons / 档案馆开放库）。
* **Probe-Beta（力学与本构穿透探针）**：
  * **事实挖掘**：穿透 PR 营销公关词汇，探究核心受力与物理机制：
    * **空间钢结构**：支座反力传递路径、外压环与内拉环自平衡、可开合动力机构与折叠膜运动学、减隔震支座与临时托换力学；
    * **超高层建筑**：高宽比、巨型组合柱、伸臂桁架、风致振动与阻尼器（TMD/粘滞阻尼器）；
    * **交通枢纽**：空铁轨接驳动线、高峰小时人流通量、大跨悬挑挑篷防风吸；
  * **【视觉响应 5~7】**：必须配齐三类深层透视工程图谱（严禁纯表面照片）：
    1. **托换/深基坑三维轴测工程剖切图（3D Cutaway）**：展示悬空受力、临时立柱、基坑支护排桩与地锚空间拓扑；
    2. **三维有限元（FEA）应力与位移彩虹云图**：展示 Von Mises 应力集中红黄蓝梯度与动力解耦/抗震熔断机制；
    3. **特色水工/暖通全流程微气候图**：如“雨水成冰”、地热梯级利用或大跨流体力学 CFD 流速场。
* **Probe-Gamma（对抗与隐患质疑探针）**：
  * **事实挖掘**：主动寻找反例与隐患：造价与工期狂飙、深地高压锅效应与逆重力疏散极限、碳中和与购电协议（VPPA）漂绿争议、老旧承重构件微裂纹疲劳与地震剪切破坏；
  * **【视觉响应 8~9】**：
    1. **极端灾害/安全疏散动力学剖切图解**：如地下火灾浮力排烟与加压正压楼梯间逆重力疏散流场图；
    2. **满负荷真实运营承载实况**：高密赛事日室内全景（展现无柱大跨震撼度与高负荷运行真实状态）。

## 阶段 3：五级出处信度拓扑仲裁（Evidence Hierarchy）

当不同渠道数据发生冲突（如用钢量、跨度、疏散时限、造价）时，依据五级信度拓扑进行仲裁，详见规范指南：
👉 **[五级出处信度权重与冲突消解规范](./references/provenance_hierarchy.md)**

* **W1 级（最高，100% 采信）**：主持大师/结构总工签名图纸、学术学报论文（IASS, ASCE, SBP 学术论文集）、发明专利；
* **W2 级（90% 采信）**：国家/国际行业规范标准（Eurocode, AISC, GB 规范）、政府验收审计报告；
* **W3 级（80% 采信）**：总承包商工法技术总结、现场传感器监测日志（SHM Logs）；
* **W4 级（65% 采信）**：专业建筑/工程期刊杂志深度报道（如《Detail》、《Structure Magazine》）；
* **W5 级（30% 审慎）**：商业宣传通稿、体育新闻、维基百科（存在公关夸大或口径混淆时做纠偏提示）。

## 阶段 4.5：全流程章节级图文闭环范式（Chapter-by-Chapter Visual Evidentiary Synthesis）

为彻底杜绝“长篇文字枯燥堆砌”与“图片集中在文末走过场”的弊病，本技能确立以下四项视觉铁律：

### 1. 铁律一：正文就地内嵌，拒绝文末堆砌（In-situ Inline Embedding）
* 每一个章节/探针推演结论得出后，**必须立即在该章节正文下方插入专属视觉证据**；
* 图片下方必须配有规范的斜体详细工程图注：包含图号、图像名称、力学与系统机理说明，以及明确的视觉信度分级（如 `[出处信度: V1 级，西雅图历史档案局]` 或 `[出处信度: V3 级受控工程图谱]`）。

### 2. 铁律二：网络真实摄影第一优先（Network First）
* 对于历史母体、施工实录、现场大样、宏观现状，严禁无端臆造，必须优先通过网络检索与下载开放档案库（Wikimedia Commons、主创建筑师官网、总包商工法日志、学术期刊论文图纸）；
* 只有当真实图片无法直接拍摄深层不可见力学机理时，才进入第二级 AI 合成。

### 3. 铁律三：基于实证素材与物理计算锚定的 AI 工程图谱合成（Grounded Infographics）
* 当表达**有限元受力云图（FEA）**、**逆作托换三维剖切图（Cutaway）**、**流体力学/防排烟流场（CFD）**、**系统水工闭环流程**以及**信度沙盒仪表盘**时，使用 AI 信息图表合成；
* **素材锚定硬约束**：AI 生图提示词中必须显式输入网络检索到的真实几何跨度、构件尺寸、吨位、锚索数、计算耗时等参数，保持 CAE/BIM 蓝图级的专业严谨度，严禁生成任何科幻、卡通或虚构图像。

### 4. 铁律四：产物目录与仓库镜像双轨固化（Dual-Track Persistence）
* **会话交互轨**：下载或生成的图像统一保存在当前会话产物目录 `<appDataDir>\brain\<conversation-id>\images\`，报告中使用标准绝对路径内嵌；
* **仓库沉淀轨**：同步将全套报告与图像复制到代码仓库 `docs/research/<project_slug>/`，并将镜像报告中的图片引用路径自动替换为 `./images/<name>.jpg` 相对路径，确保在 GitHub 与各类离线 Markdown 渲染器中永久无损显示。

## 阶段 5：结构化交付标准（Professional Brief & Visual Output）

最终交付的项目专业简报或技术专著必须包含以下标准模块，并严格保证图文贯通：

1. **时空与事件定位**：严格以系统当前时间为锚点，明确赛事/会议名称、精确日期与交通枢纽空铁接驳；*(配图 1：项目全景与工程联合体网络图板)*
2. **出处源流与范式演变（Probe-Alpha）**：清晰梳理项目从最初母体到当今形态的进化脉络；*(配图 2~4：总师手稿图纸、母体初建工地、历史改建旧照)*
3. **核心物理与工程技术精剖（Probe-Beta）**：大跨受力、基础托换、抗震动力解耦与特色机电水工；*(配图 5~7：三维托换剖切图、FEA应力彩虹云图、水工全流程剖面)*
4. **多维批判性思辨与运维大考（Probe-Gamma）**：剖析极端气候应对、生命周期运维痛点、逆重力防排烟与高密负荷；*(配图 8~9：逆重力防排烟流场图、高负荷赛事日实况)*
5. **数据源拓扑与沙盒参数核验（阶段 3 & 4）**：五级出处信度金字塔消解结论与力学/通量验算；*(配图 10：信度金字塔与沙盒核验双联仪表盘)*
6. **全生命周期法医级反思与终极评述（阶段 5）**：总结历史保护与现代工程技术结合的经验教训与警钟。*(配图 11：宏观现状全景实录 Hero Shot)*
